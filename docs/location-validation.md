# スマートフォン位置情報・バックグラウンド挙動検証

`/dev/location-test` は、スマートフォンのWebブラウザで `navigator.geolocation.watchPosition()` の更新頻度、精度、バックグラウンド移行および画面ロック時の挙動を記録する技術検証ページである。バックグラウンド位置取得を保証するものではない。

## 必要環境

- HTTPSで配信されたページ、または `localhost`
- GPSを利用できるスマートフォン
- サイトに対する位置情報の利用許可（可能なら「正確な位置情報」も有効化）
- SafariまたはChrome

開発サーバへスマートフォンからアクセスする場合は、PCとスマートフォンを同じLANに接続し、`pnpm dev --hostname 0.0.0.0` で起動すればページの表示確認はできる。ただし、スマートフォンで開く `http://<PCのIPアドレス>:3000/dev/location-test` は安全なコンテキストではないため、位置情報の記録には使用できない。実機で記録する際は、信頼できるHTTPSの開発用URL（HTTPS対応のホスティングまたはトンネル）を使う。自己署名証明書は、端末側で証明書を信頼する設定が別途必要になる。トンネルを使う場合は、URLや位置ログを第三者へ公開しない。

ページを開いたら「記録開始」を押し、ブラウザの位置情報確認を許可する。OSとブラウザ双方のサイト設定も確認する。JSONまたはCSVを保存するまで、再読み込みやページ遷移でメモリ上のログが失われる点に注意する。

## 検証手順

### テストA：静止状態

1. 屋外または窓際の同じ場所で記録を開始する。
2. 5分程度、端末を動かさずに記録する。
3. 緯度・経度の揺れと `accuracyM` の変化を確認する。
4. JSONとCSVを保存する。

### テストB：徒歩移動

1. 記録を開始して10〜15分程度歩く。
2. 保存済みログの `intervalFromPreviousMs` から保存間隔を確認する。この間隔は端末時刻の変更に影響されない単調増加時計で判定される。
3. 緯度・経度が時系列で記録されていることを確認する。
4. 安全のため、歩行中に画面を操作しない。

### テストC：別タブ・別アプリへ移動

1. 記録を開始し、位置が数件保存されたことを確認する。
2. 別タブへ切り替え、続いてブラウザをバックグラウンドへ移動する。
3. 音楽アプリを開いて数分待つ。
4. ブラウザへ戻り、`visibility_changed`、位置更新、保存間隔を確認する。
5. hidden中に保存された件数と、復帰直後にまとめて更新されたように見えるかを記録する。

### テストD：画面ロック

1. 記録を開始し、位置が数件保存されたことを確認する。
2. 画面を1〜3分ロックする。
3. ロック解除後にイベント履歴と位置ログを確認する。
4. ロック中に位置更新が停止したか、復帰後の保存間隔が長くなったかを記録する。

### テストE：位置情報拒否

1. ブラウザのサイト設定をリセットするか、位置情報を拒否する。
2. 記録開始後に `PERMISSION_DENIED` と復旧案内が表示されることを確認する。
3. サイト設定で位置情報を許可し、ページを再読み込みして記録を再開できることを確認する。

### テストF：長時間記録

1. 30分程度記録する。
2. 保存件数、画面の応答、端末のメモリ使用とバッテリー消費の体感を記録する。
3. 開始ボタンを再度押してもwatchやタイマーが重複しないことをイベント履歴で確認する。
4. 停止後に新しい位置イベントが追加されないことを確認する。

画面負荷を一定にするため、位置ログは直近200件だけを表に描画する（JSON／CSVには全件を出力する）。イベントは直近1,000件を保持し、そのうち直近200件だけを描画する。

## 合格条件

- 前面表示中に継続して位置情報を取得できる。
- 各位置情報に取得時刻が付く。
- 10秒以上の間隔で時系列ログを保存できる。
- accuracyを記録できる。
- JSON・CSV出力ができる。
- watchが重複起動しない。
- 停止時に `clearWatch()` が呼ばれ、以後の更新が止まる。
- バックグラウンド・画面ロック時の端末／OS／ブラウザごとの制限を把握できる。
- 既存の `/dev/lastfm-test` と `/api/lastfm/recent` が従来どおり動作する。

## 出力データの扱い

位置ログは個人の行動を特定し得るデータである。卒業論文の検証データとして扱う際は、共有範囲、保存場所、保管期間を決め、不要になったファイルを削除する。今回のページはLast.fmとの結合、データベース保存、地図表示を行わず、データはページのメモリ上にだけ保持する。
